# Free tools: learn without an API key

You do not need a paid API key to follow this series. These free websites let you try the ideas in your browser.

| Tool | What you can try | Link |
|---|---|---|
| OpenAI Tokenizer | Paste text and see how it splits into tokens. Free. It may ask you to sign in; no payment is needed. | https://platform.openai.com/tokenizer |
| Tiktokenizer | Token counts for several models side by side. Free, no account. | https://tiktokenizer.vercel.app |
| Transformer Explainer | A small GPT-2 running in your browser. Type a prompt, move the temperature slider and watch the next-token probabilities change. Free, no account. | https://poloclub.github.io/transformer-explainer/ |
| LLM Visualization | A 3D walkthrough of every step inside a tiny GPT. Free, no account. | https://bbycroft.net/llm |
| Google AI Studio | A real model with temperature, top-p, thinking level and output length controls. Needs a Google account, no credit card. Do not paste private data: free-tier prompts may be used to improve Google products. | https://aistudio.google.com |
| Embedding Projector | Explore word embeddings in 3D and find nearest neighbours. Free, no account. | https://projector.tensorflow.org |
| Gandalf | A game: trick a model into revealing a password. The quickest way to feel prompt injection. | https://gandalf.lakera.ai |

Each part's README lists the tools that fit that part.
